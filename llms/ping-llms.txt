# Ping++

> Ping++ (operated by Shanghai Jianmi Network Technology Co., Ltd. / 上海简米网络科技有限公司) is a Chinese aggregated-payment (聚合支付) platform. A single Stripe-style REST API and multi-platform SDKs let merchants accept payments across WeChat Pay, Alipay, UnionPay and bank cards, run compliant profit-sharing / split-settlement (分账), enterprise payouts, red envelopes, member-account systems and multi-tier merchant systems. Venture-backed by General Catalyst and Ribbit Capital.

Key facts:
- API base URL: https://api.pingxx.com/v1 (REST, JSON responses, HTTPS required)
- Authentication: HTTP Basic Auth — API Key as username, empty password. Keys are prefixed sk_live_ (production) and sk_test_ (test mode).
- Pagination: cursor-based via limit (1-100), starting_after, ending_before; list responses carry object=list, url, has_more, data[].
- Errors: custom JSON error object with type (invalid_request_error, api_error, channel_error, card_error), message, optional code and param.
- Webhooks: outbound POST JSON Event objects; ack with 2xx; retried up to 10 times over ~25h.
